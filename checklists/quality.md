# 教程质量清单（P5 审查用，G4 门槛）

> 用法：每节生成后逐项过。L1 = 人工 30 秒（结构）；L2 = AI 按 rubric 初筛（可选）；L3 = 真实执行/反馈（唯一质量证明）。
> 反形式主义：审查记录必须写「拦截了什么」；全勾通过视为可疑；**门槛拦截数必须 >0**，从未拦截 = 门槛失效，修订门槛。

## 九项标准

| # | 标准 | L1 检查（人工） | L3 验证（执行/反馈） | 判定 |
|---|---|---|---|---|
| 1 | 学习目标明确 | 节头声明映射的验收标准 ID | 学完觉得「学的不是要学的」→ 回 P1 | |
| 2 | 前置知识充分 | 前置清单与本节首段对照 | 「缺前置」类追问 | |
| 3 | 术语易懂 | 术语首现即有解释 | 术语类追问 | |
| 4 | 步骤细致 | 一动作一步；命令独立成块可复制 | 每步照做成功 | |
| 5 | 预期结果明确 | 每步含「预期输出」字段 | 实际输出与预期一致 | |
| 6 | 示例可执行 | — | **每条命令真实跑通（唯一证明）** | |
| 7 | 常见错误完整 | 错误三段式（现象/原因/恢复） | 真实错误归档 | |
| 8 | 检查与练习 | ≥1 检查点 + ≥1 练习（含通过线） | 练习真实完成 | |
| 9 | 迁移检验 | 变式任务存在且映射 E5 类标准 | 照抄测试：变式不能照抄完成 | |

## 三态流转

`草稿`（生成未审查）→ `已审查`（本清单 L1/L2 全过）→ `已验证`（L3：命令跑通 + 练习完成）
**只有「已验证」的节可被复用进其他模块。**

## 审查记录格式（每节一行，追加在教程文件末尾）

```
[审查] 日期 ｜ 节名 ｜ 拦截了：#5 步骤2缺预期输出、#8 练习无通过线 ｜ 处置：回 P4 重生成该节 ｜ 状态：草稿→已审查
```
