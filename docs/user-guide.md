# AI Edu 用户指南（v0.1 本地版）

本指南对应 v2.0 执行基线的第一版实现：一个可本地运行、数据可持久化的完整学习闭环。

## 一、启动

### 后端（端口 8000）

```powershell
cd services/api
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- API 文档：http://127.0.0.1:8000/docs
- 数据文件：`services/api/data/aiedu.db`（SQLite，可直接备份）
- 首次启动自动建表。

### 前端（端口 3000，被占用时会自动改用 3001）

```powershell
cd apps/web
npm install
npm run dev
```

打开终端提示的地址（http://localhost:3000 或 3001）。

### 模型配置（可选）

仓库根目录 `.env`（从 `.env.example` 复制）：

```
LLM_BASE_URL=https://your-provider/v1
LLM_API_KEY=sk-...
LLM_MODEL=your-model
```

填好后重启后端。未配置时运行于**演示模式**：所有生成内容标注「演示模式」，结构完整但不代表真实模型输出。

## 二、一次完整学习闭环（在界面上操作）

1. **创建目标**（学习目标 → 创建）：写明目标、学科（计算机/命令行 或 数学/数据分析）、动机、应用场景、当前基础与可投入时间。
2. **价值诊断**（目标页 ①）：运行诊断 → 阅读收益/前置/替代路径/假设/不确定项 → 自己作出「继续 / 调整 / 暂缓」决定并填理由（AI 不替你决定）。
3. **学习计划**（②）：生成计划 → 6 个左右的步骤，可对照调整。
4. **验收标准**（③）：生成 4–5 条可观察标准 → 逐条**确认**。未确认前不能生成教程（先标准、后教程）。
5. **教程**（④）：先生成大纲 → 再生成全部章节；每章含步骤（预期结果 + 验证方式）、练习、变式任务、常见错误与来源；生成后自动执行质量检查（结构、双向映射、覆盖、练习与变式、来源）。
6. **实践任务**（⑤）：章节生成后自动创建任务 → 粘贴产物（命令输出/代码/推导）→ 选择辅助等级（A0–A3）→ 提交 → 获得逐条验收反馈。
7. **能力评估**（⑥）：生成独立任务 + 变式任务 + 评分维度 → 执行后记录结果与薄弱点。
8. **复盘**（⑦）：生成复盘草稿 → 确认或修改；系统会记录证据引用。
9. **知识提议**（右列）：生成知识提议 → 逐条确认/拒绝；确认后进入知识网络。只有确认过的关系才是「确定知识」。

## 三、数据备份与恢复

- 偏好设置 → 下载 JSON 备份（包含全部学习数据）。
- 导入备份会**覆盖当前数据**；导入前自动生成备份文件（`services/api/data/backups/`）。

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 页面提示「无法连接后端」 | 确认 uvicorn 已启动（端口 8000），或检查 CORS 配置 |
| 3000 端口被占用 | Next 会自动改用 3001；或 `npm run dev -- -p 3000` 指定端口 |
| 模型调用失败（502） | 检查 `.env` 的 Base URL / Key / Model；确认网络可访问该服务商 |
| 安装依赖很慢 | 使用镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`；npm 使用 `--registry=https://registry.npmmirror.com` |
| 想清空数据 | 停止后端，删除 `services/api/data/aiedu.db` 后重启 |

## 五、版本边界

- 单用户、本地运行；公网部署前必须增加访问保护（v1 不宣称多用户安全）。
- 生成内容需核验：模型自评不能作为准确性保证。
- 演示模式内容不得作为真实学习证据。
- 跨学科：内置计算机/命令行与数学/数据分析两套配置；新学科通过 `app/learning/disciplines.py` 扩展。
