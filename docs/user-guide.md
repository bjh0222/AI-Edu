# AI Edu 用户指南（v0.1 本地版）

本指南对应 v2.0 执行基线的第一版实现：一个可本地运行、数据可持久化的完整学习闭环。

## 一、启动

### 一键启动（推荐）

- **方法一（保留 Windows「智能应用控制」）**：打开「Windows PowerShell」，输入 `aiedu` 回车。
- **方法二（双击）**：双击 `ai-edu\启动 AI Edu.cmd`（需先关闭「智能应用控制」，否则会被系统拦截）。

两种方式都会启动后端（8000）与前端（3001）两个窗口，并打开浏览器 http://127.0.0.1:3001。停止服务 = 关闭这两个窗口。

**手机（安卓 / iOS）访问**：改用 `scripts\start-dev.ps1 -Mobile`（或 `启动 AI Edu.cmd -Mobile`）启动——
前后端监听 0.0.0.0，脚本会打印手机要访问的局域网地址（如 `http://192.168.1.20:3001`）。
手机与电脑需连同一个 Wi-Fi，且电脑防火墙放行 TCP 8000 / 3001。网页端在手机上有底部标签栏导航，
知识网络图谱支持单指拖动、双指捏合缩放。

> 若双击 .cmd/.lnk 时提示「智能应用控制已阻止不安全文件」：这是 Windows 11 对危险脚本扩展名的拦截。改用 `aiedu` 命令即可；或到「设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制」关闭该功能（关闭后不可恢复，需重装系统才能重新开启）。

### 手动启动（后端）

```powershell
cd services/api
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- API 文档：http://127.0.0.1:8000/docs
- 数据文件：`services/api/data/aiedu.db`（SQLite，可直接备份）
- 首次启动自动建表。

### 前端（默认 3001，被占用时自动顺延）

```powershell
cd apps/web
pnpm install      # 本仓库前端用 pnpm（见 pnpm-lock.yaml）；也可用 npm install
pnpm dev
```

打开终端提示的地址（通常是 http://localhost:3001）。前端所有接口走**同源 `/api`**，由 Next 服务端反向代理到 `http://127.0.0.1:8000`（见 `next.config.ts` 的 rewrites），因此无需处理跨源；如需直连其他后端，可设置 `NEXT_PUBLIC_API_BASE`。

### 模型配置（可选）

仓库根目录 `.env`（从 `.env.example` 复制）：

```
LLM_BASE_URL=https://your-provider/v1
LLM_API_KEY=sk-...
LLM_MODEL=your-model
```

填好后重启后端。未配置时运行于**演示模式**：所有生成内容标注「演示模式」，结构完整但不代表真实模型输出。

## 二、一次完整学习闭环（在界面上操作）

流程是**五个阶段，教程学习即终点**：
`目标定义 → 价值诊断 → 学习计划 → 验收标准 → 教程学习`。
目标详情页顶部的阶段条可点击跳转，已到达的阶段打勾并高亮，当前阶段带 `aria-current`。

1. **创建目标**（学习目标页 →「创建并生成教程」卡片）：填写目标名称 *、学科 / 领域
   （21 个一级学科）、为什么要学、学完要能做什么、当前基础、硬性约束、可投入总时间、
   能力层级（L1 基础理解 / L2 独立应用 / L3 深入掌握与迁移）、生成挡位（快速 / 标准 / 深度）、
   教程规范，以及可选的「参考资料 / 例题来源」文件。
   - **教程规范**：下拉按「教程规范 / 练习与试卷规范 / 其他规范」分组（分组只看 scene，
     不影响提交语义：自动匹配 → null、不使用 → 空串、手动 → 规范 id）；点「查看规范」可就地
     展开该规范的规则正文，段落顺序与生成时注入提示词的顺序一致。Obsidian 插件里有同语义的一栏。
   表单内容自动暂存，刷新不丢失。
   - **创建并自动生成教程**：一次跑完价值诊断 → 学习计划 → 验收标准（自动批量同意）→ 大纲 → 全部章节，
     成功后直接跳到教程页。
   - **仅创建目标**：只建目标，之后自己在各阶段逐步操作。
2. **价值诊断**（目标页 ①）：运行诊断 → 阅读收益 / 前置条件 / 替代路径 / 假设 / 不确定项 →
   自己作出「继续 / 调整 / 暂缓」决定并填理由（AI 不替你决定）。
   若 AI 明确判断不值得推进，生成会**暂停**并给出三个选项：坚决执行 / 采纳 AI 建议后立即执行 / 修改计划。
   同一页可上传参考资料与例题来源作为诊断依据。
3. **学习计划**（②）：生成计划 → 若干有序步骤，可对照调整。
4. **验收标准**（③）：生成可观察标准 → 逐条**确认**，或点「一键同意全部」
   （不会覆盖你已显式拒绝的条目）。未确认前不能生成教程——**先标准、后教程**。
5. **教程学习**（④，终点）：先生成大纲 → 再生成全部章节。**章节生成是后台任务**：
   界面显示进度与阶段文字，期间可以离开页面，回来即可看到结果，任务不会中断。
   生成后自动执行质量检查（大纲与章节齐备、章节映射验收标准、验收标准双向覆盖、
   正文非空、内容块类型合法）。大纲的每一步、每个章节都能点进独立详情页
   （`/tutorials/[tid]`、`/tutorials/[tid]/sections/[sid]`），单节可「重新生成本节」
   （重生成期间互斥禁用，避免并发覆盖版本）。
   教程页显示「历史 N 个版本」，每次重生成都会落一个新版本。
   若生成失败，已完成章节保留为草稿版本，重试即可继续。

教程学习页还提供两块辅助能力：

- **学习反馈**：对教程打分（有帮助 / 需改进）+ 标签 + 评论；反馈持久化到 `training_records`，
  随训练数据一起导出。
- **上下文答疑**：基于当前目标与教程上下文提问（优先给提示，不直接代做）。

> **旧版说明**：早期版本在本页还有「⑤ 实践任务 / ⑥ 能力评估 / ⑦ 复盘 / 知识提议」四个环节，
> 现已从界面移除。对应后端能力（`POST /api/goals/{id}/tasks`、`/attempts`、`/assessments`、
> `/reflections`、`/knowledge-proposals`）仍然可用，知识网络的掌握度计算也会读取实践尝试记录；
> 停留在旧阶段状态的历史目标，列表页仍能正确显示中文阶段徽章。

**知识网络**（左侧导航）是跨目标的全局视图：教程生成后自动在后台提取概念与关系
（带指纹去重，重复触发不会重复消耗 token），以 SVG 力导向图展示，支持按领域 / 目标筛选、
聚焦、缩放、去重合并与手工增删概念和关系。

## 三、数据备份与恢复

- 偏好设置 → 下载 JSON 备份（包含全部学习数据）。
- 导入备份会**覆盖当前数据**；导入前自动生成备份文件（`services/api/data/backups/`）。

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 页面提示「无法连接后端」 | 确认 uvicorn 已启动（端口 8000）；前端经同源 `/api` 代理访问 |
| 页面一直「加载中」 | 硬刷新（Ctrl+F5）以清除旧缓存；确认 dev 服务器在终端提示的端口上运行 |
| 3001 端口被占用 | Next 会自动顺延；或 `npm run dev -- -p 3001` 指定端口 |
| 模型调用失败（502） | 检查 `.env` 的 Base URL / Key / Model；确认网络可访问该服务商 |
| 安装依赖很慢 | 使用镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`；npm 使用 `--registry=https://registry.npmmirror.com` |
| 想清空数据 | 停止后端，删除 `services/api/data/aiedu.db` 后重启 |
| 测试数据页报 `unable to open database file` | 这是排序时 SQLite 需要写磁盘临时文件、而临时目录不可写导致的。已修复：`training_records.created_at` / `model_call_logs.created_at` 建了索引（排序走索引序，不再产生临时文件），`db.py` 的 `_migrate_sqlite_indexes()` 会在启动时给老库自动补上。若仍出现，检查系统临时目录权限，或临时设置 `PRAGMA temp_store=MEMORY` |
| 换目录启动后模型配置「消失」 | 模型配置、数据库、材料、备份路径都锚定到 `services/api/`，与启动时的工作目录无关。若你自己设了相对的 `MODEL_SETTINGS_FILE` / `BACKUP_DIR`，它们同样按 `services/api/` 解析 |

## 五、版本边界

- 单用户、本地运行；公网部署前必须增加访问保护（v1 不宣称多用户安全）。
- 生成内容需核验：模型自评不能作为准确性保证。
- 演示模式内容不得作为真实学习证据。
- 跨学科：内置计算机/命令行与数学/数据分析两套配置；新学科通过 `app/learning/disciplines.py` 扩展。
