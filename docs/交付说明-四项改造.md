## 二、实现要点

### 1）列表到详情链路
- `/goals` 每项「查看」使用 `next/link`，客户端路由进入 `/goals/{id}`（保留标题链接与归档）。
- 教程大纲的每一项都可点击：已有章节 → `/tutorials/{tid}/sections/{sid}`；仅有大纲 → `/tutorials/{tid}#outline-{i}`。
- 教程详情页列出全部章节，每节可「单独打开」；目标详情页的章节卡片同样提供「查看详情 →」。
- 章节详情页提供上一节 / 下一节 / 返回教程 / 回到目标工作区，形成完整链路。

### 2）一键生成 + 一键同意
- `quickstart` 逐步执行并返回每步状态（created / reused / running）与 `job_id`：
  - 已有诊断 / 计划 / 标准 / 大纲 / 章节时跳过，不重复调用模型；
  - 已有运行中的分节任务时复用该 job，避免并发重复生成；
  - 分节仍是后台任务，前端轮询进度并展示已消耗 token。
- 验收标准「一键同意全部（N）」批量把 pending 置为 confirmed；`rejected` 保持原状，尊重用户已作决定。
- 失败语义：单步失败保留此前已提交成果；大纲失败会清理未产出内容的空壳教程。

### 3）token 统计
- Provider 返回 `usage` 时按实测记录；缺失时按字符估算（CJK≈1 字 1 token，其他≈4 字符 1 token），`usage_source=estimated`，界面明确标注「按字符估算」。
- 三层累计：单次调用（ModelCallLog）→ 任务（GenerationJob）→ 版本（TutorialVersion）；教程累计按调用日志汇总并回退版本字段。
- 展示位置：目标详情教程卡片（累计 badge、本次/教程/目标 TokenLine、生成中已用 token、每节 token）、教程详情（按功能分布、实测/估算调用数）、章节详情（本节 token）。
- 新增 `GET /api/goals/{id}/usage`，兼容无 usage 字段的提供方。

### 4）测试版数据采集与导出
- 每次生成成功都会写入 `training_records`：`source_type=material`，含 system/user prompt、输出原文、模型、token、goal/tutorial/section 关联、context（demo 标记）。
- 用户反馈写入 `source_type=feedback`：rating(1/-1)、标签、评论、目标/教程/章节、页面路径；服务端校验目标/教程/章节存在。
- `/training` 页面展示材料数、反馈数、目标数、token 总量、按功能分布与最近记录（分页加载）。
- 导出：`/api/training/export` 默认 JSONL（material 为 `messages` 结构；feedback 含 feedback/target/context），支持 `source_type`、`goal_id`、`exclude_demo`、`fmt=json`。反馈属于真实用户数据，`exclude_demo` 只过滤演示模式生成的材料。
- 数据随「导出备份 / 导入」整体迁移（`training_records` 已加入备份表清单）。

### 数据迁移
- 启动时 `init_db()` 会为旧 SQLite 表补列（token 字段、关联字段），不改动既有行；新表 `training_records` 由 `create_all` 创建。
- 旧教程 / 旧调用没有关联日志，token 显示为 0（无历史数据可回溯）；新生成从第一次调用开始累计。

## 四、遗留问题与注意事项

1. **旧数据 token 为空**：历史教程与调用发生在字段引入前，界面显示 0；如需统计只能从新生成开始。未做历史回填（无原始 usage 可依据）。
2. **估算精度**：演示模式与无 usage 提供方的 token 为字符启发式估算，仅用于成本感知，不能作为计费依据；界面与导出均带 `estimated` 标记。
3. **真实模型成本**：一键生成会一次调用多次模型（诊断/计划/标准/大纲 + 每节），建议在测试环境先跑演示模式；界面已显示进度与累计 token。
4. **并发**：quickstart 复用在跑的分节任务，但同一目标被两个浏览器同时点击时，仍可能各自创建大纲/标准（单用户本地场景可接受）；如需严格幂等可加目标级锁/任务去重键。
5. **反馈数据与隐私**：训练材料包含 prompt 与用户输入（如目标描述、实践产物），导出前请确认不含敏感信息；当前仅本机存储。
6. **导出格式**：JSONL 的 `messages` 结构面向常见指令微调；若后续训练框架需要其他字段（如 `instruction/input/output`），可在导出层增加格式选项。
7. **验收标准全部被拒绝**：一键生成会因「无已确认标准」返回 409（与既有先标准后教程规则一致），需先调整或确认至少一条。
8. **备份导入的替换语义**：导入旧版备份（不含 `training_records`）会按现有导入逻辑清空训练记录后再导入空表；建议升级后先导出一次新备份再导入旧数据。
