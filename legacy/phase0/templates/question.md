# 中途提问模板（学习中随时用）

> 用途：卡住时，组装一份自包含提问，贴进 AI Hub 输入框 → 点平台卡（复制+打开）→ 新标签 Ctrl+V。
> 技术边界（不假设做不到的事）：无法自动读取模型网页的对话、无法自动回收回答——判断与记录靠你，各花 30 秒。

## 模板

```
[背景一句话] 我在学 Windows PowerShell 命令行（模块：文件与目录导航 / 第 2 节），环境 PowerShell 5.1。

[我的水平] 已会：cd、Get-ChildItem 基本用法；正在学：Filter 参数。

[教程原文] （出问题的步骤/解释，原样复制）
Get-ChildItem -Path "$root\data\cats_dogs\raw" -Filter "*.jpg" -File

[我已尝试] 我运行了（原命令），实际输出是（粘贴），与教程预期（写预期）不一致 / 输出了但我看不懂。

[具体困惑] 用一句话：我是 A（概念理解错：…）还是 B（教程这步有问题/漏了前置：…）？

[期望回答] 先一句话结论，再展开。如果是教程问题，指出缺了什么前置或哪步该修。
```

## 提问后 30 秒：记一行进 learning-log.md

| 字段 | 取值 |
|---|---|
| 问题类别 | 解释不清 / 步骤失败 / 缺前置 / 环境差异 / 其他 |
| 是否解决 | 是 / 部分 / 否 |
| （若「否」）怎么解决的 | 一句话 |

## 负担控制

单次记录 ≤2 分钟。若实测超了，砍到只记「未解决」与「步骤失败」两类。
