# 生成 Prompt 组装模板（P3 大纲 / P4 分节用）

> 用途：每次让网页模型生成教程内容前，按此顺序组装 prompt，贴进 AI Hub 输入框，点平台卡复制+打开。
> 原则：模型不继承任何上下文——每次都必须自包含。缺一段就补一段，不省略。

## 组装顺序

```
[1] 角色+任务（一句话）
你在为一个 Windows PowerShell 学习者生成教程的一个小节。

[2] 画像摘要（从 profile.md 取三行）
环境：Windows PowerShell 5.1；起点：了解概念但记不住命令语法（已会：cd/…）；
风格：中文为主，命令与术语保留英文；辅助等级：A0–A1。

[3] 本节验收标准（从 acceptance.md 原文粘贴，逐条）
学完本节，学习者必须能够：…

[4] 大纲定位（本节在模块中的位置 + 前一节已学会什么）
本节是「文件与目录导航」第 2 节；第 1 节已学会进入/退出目录。

[5] 范例（如有：一个合格小节的样例，或一个反面样例+批注）
（Phase 1 起逐步积累；没有就写「暂无范例」）

[6] 输出要求（硬性结构）
- 每个操作步骤必须包含：命令块 + 一句话作用 + 预期输出（具体到能比对的程度）
- 术语首次出现必须当场解释，不得只给英文名
- 结尾含：1 个理解检查点（问题形式）+ 1 个动手练习（含通过线）
- 长度硬上限：一个 40 分钟单元能学完的量；不确定的内容标注「待核实」，不得编造
- 练习必须不能仅靠照抄本节命令完成（变式）
```

## 使用规则

1. **先确认 [3] 再组装**——验收标准未过 G1，不进入生成（铁律 1）
2. 每次生成后，在 `tutorial-log.md` 记一行（用了哪个平台/几轮对话/几处不满意）
3. 生成结果不满意时：**说清具体缺陷**（「步骤 3 没有预期输出」），不写「再通俗一点」——模糊指令是重复润色的入口，基线教程就是这么变厚的
4. 换平台重试同一节 = 免费的 A4 对照数据，记得在 log 里标注
