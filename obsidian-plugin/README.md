# AI Edu Tutorial Delivery（本地 Obsidian 插件）

这是一个个人使用的 Obsidian 插件，不发布到社区插件市场。

## 功能

- 输入界面与 AI Edu 网站「创建并生成教程」一致：目标名称、学科 / 领域、为什么要学、
  学完能做什么、当前基础、硬性约束、格式规范、可投入总时间、能力层级、生成挡位、额外练习文件。
- 「教程规范」一栏与网站同语义：自动匹配 / 本次不使用特殊规范 / 手动选择；打开弹窗时
  从 `GET /api/format-specs` 拉取候选（后端不可达时保留前两项兜底），选择会记住到插件设置。
  下拉按「教程规范 / 练习与试卷规范 / 其他规范」分组（分组只看 scene，不影响提交语义），
  并能就地展开所选规范的规则正文（内容结构 / 必须遵守 / 禁止出现 / 参考示例等）——
  手机上不用回网页翻「偏好设置 → 格式规范」就能确认规范内容。
- 打开弹窗即自检后端连通性（`GET /api/health`）：连不上时状态行直接给出可执行的排查步骤
  （手机上 127.0.0.1 指向手机自己，是最常见的连不上原因）。
- 支持「参考资料 / 例题来源（可选）」暂存式上传：文件先留在本地并按后端规则校验，
  提交时先创建学习目标，再逐个上传到 `/api/goals/{id}/materials`，随后触发生成；
  材料上传失败不会重复创建目标（重试只补传材料）。
- 调用本地 AI Edu API 的统一生成接口（目标、价值判断、计划、验收标准、教程一次生成）。
- 关闭弹窗即清空本次填写内容，并提示「已清空本次填写内容」；也可只创建目标（`仅创建目标`）。
- 轮询生成进度，成功后把教程 Markdown **以及配套文件**（知识速查、额外练习）写入
  指定 Vault 目录；随后自动关闭弹窗、清空内容，并在 Obsidian 中打开新教程。
- 写入后校验双链：主教程与配套文件互相指向时能解析；发现未解析链接会在通知里列出。
  校验会跳过代码块与数学环境（`$...$` / `$$...$$`）：数学记号里的 `[[...]]`
  （如形式幂级数环 `R[[x]]`）不是双链，不会误报。
- 写入成功后回写 AI Edu 的交付状态。
- 主教程与配套文件重名时统一追加 `v2`、`v3` 等后缀，同步改写三者内部的双链，不覆盖已有笔记。

## 与网站的对应关系

| 网站字段 | 插件行为 |
|---|---|
| 目标名称 * | 作为 `title` 提交；为空时不允许提交 |
| 学科 / 领域 | 21 个一级学科（S01–S21），默认「计算机科学与信息技术」 |
| 为什么要学 / 学完能做什么 / 当前基础 | 原样提交，并拼进统一需求文本 |
| 硬性约束（可选） | 作为 `hard_constraints` 提交；后端会注入价值判断、计划、验收标准、教程与配套文件的全部生成提示词，生成内容必须逐条满足 |
| 教程规范 | 下拉候选来自 `GET /api/format-specs`，按族分组展示并可就地查看规范正文；`自动匹配`→`format_spec_id=null`、`本次不使用特殊规范`→空串、手动选择→规范 id；无材料时随 `POST /api/goals/quickstart` 提交，带材料时随 `POST /api/goals/{id}/tutorials/quickstart` 提交，暂停续跑时一并携带 |
| 可投入总时间 | 默认「共 10 小时」，不做每日拆分 |
| 能力层级 | L1 基础理解 / L2 独立应用 / L3 深入掌握与迁移 |
| 生成挡位 | 快速 / 标准 / 深度，默认取插件设置 |
| 额外练习文件 | 勾选后额外生成独立练习文件，并在教程中建立双链 |
| 参考资料 / 例题来源（可选） | 分类切换（参考资料 / 例题来源）+ 多选文件，扩展名与大小上限取自 `GET /api/materials/limits`（后端不可达时用内置默认值）；与网站创建页同规则的暂存式上传 |
| 创建并生成教程 | 无材料时调用 `POST /api/goals/quickstart`；带材料时改为「`POST /api/goals` → 逐个上传材料 → `POST /api/goals/{id}/tutorials/quickstart`」并等待后台任务 |
| 仅创建目标 | 调用 `POST /api/goals`，不生成教程；带材料时创建目标后同样上传材料 |

## 手机端（安卓 / iOS）

插件 `isDesktopOnly` 已关闭，Obsidian 移动端可直接安装使用；网页端同样做了手机适配
（底部标签栏导航、图谱单指拖动 / 双指捏合、无横向滚动）。

1. **电脑端以手机模式启动**（前后端监听 0.0.0.0 并打印局域网地址）：

   ```powershell
   scripts\start-dev.ps1 -Mobile        # 或：启动 AI Edu.cmd -Mobile
   ```

   首次启动时 Windows 防火墙弹窗选「允许」；否则在防火墙放行 TCP 8000 与 3001。

2. **手机与电脑连同一个 Wi-Fi**，在 Obsidian 移动端安装本插件（把
   `main.js` / `manifest.json` / `styles.css` 放进 Vault 的
   `.obsidian/plugins/ai-edu-tutorial-delivery/`，或用 Obsidian Sync 同步）。

3. **插件设置里把 API base URL 改成电脑的局域网 IP**，例如
   `http://192.168.1.20:8000`（启动脚本会打印；`-Mobile` 模式下后端监听 0.0.0.0）。
   填 127.0.0.1 / localhost 在手机上指向手机自己，连不上。

4. 打开「生成并保存教程」弹窗：状态行会自动自检连通性；连不上时给出排查顺序。
   手机端刻意不自动聚焦输入框（避免软键盘盖住表单），软键盘回车不会误触发提交。

网页端手机访问：浏览器打开 `http://<电脑局域网IP>:3001`（`-Mobile` 模式会把局域网 IP
加入 Next 的 dev origin 白名单）。

## 本地安装

1. 启动 AI Edu 后端：

   ```powershell
   cd services/api
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
   ```

2. 在 Obsidian Vault 中创建插件目录：

   ```text
   <Vault>/.obsidian/plugins/ai-edu-tutorial-delivery/
   ```

3. 把本目录的 `main.js`、`manifest.json`、`styles.css` 复制到上面的目录。

4. 在 Obsidian 中打开：

   `Settings → Community plugins → Turn on community plugins`

   然后启用 **AI Edu Tutorial Delivery**。

5. 打开插件设置，确认：

   - API base URL：`http://127.0.0.1:8000`
   - Vault folder：默认 `学习`，教程会写到 `<Vault>/学习/`

## 使用

- 点击左侧 Ribbon 的书本图标，或运行命令 **生成并保存教程**。
- 按网站同样的字段填写，点击 **创建并生成教程**。
- 生成成功后弹窗自动关闭，并跳转到 Vault 中新生成的教程；关闭弹窗（取消 / Esc）会清空本次填写并提示。
- 生成失败时可在 AI Edu 网页查看目标与任务状态。
- 交付失败时可点击弹窗中的 **重试交付**；这不会重新生成教程。
